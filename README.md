# Чат‑бот для университета «Синергия»

Простой консольный чат‑бот на Python для ответов на типовые вопросы студентов и абитуриентов: расписание, контакты, личный кабинет, LMS, поступление, сессия.

## Цель
Автоматизировать справочные ответы и снизить нагрузку на техподдержку и деканат за счёт обработки типовых запросов по ключевым словам.

## Целевая аудитория
Абитуриенты и студенты университета «Синергия», которым нужна оперативная справочная информация.

## Реализованные сценарии
- Приветствие и навигация по темам.
- Расписание и сессия.
- Контакты.
- Личный кабинет и LMS.
- Подача документов и поступление.

## Как запустить
1. Убедитесь, что установлен Python 3.x.
2. Скачайте или клонируйте репозиторий.
3. В терминале перейдите в папку проекта.
4. Запустите:
   ```bash
   python simple_synergy_bot.py
